## 三、分镜脚本（总时长约 55 秒）

### 镜头 1｜0-6s：打开就能排，不注册也一样用
- **画面**：首页 → 鼠标停在头部右侧「**免费试用**」按钮（不点）→ 点首屏主按钮「**免费试用 · 无需注册**」→ 跳转 `/orders`（课程安排）。
- **操作路径**：首页 → 主 CTA → 课程安排页
- **解说词**：不用注册，打开网页就能排课。

### 镜头 2｜6-16s：录一门课，整周课表自动铺开
- **画面**：点「**添加课程**」→ 依次填：年级「初一」、科目「数学」、学生「小林」、地址「示例花园 3 栋」→ 在周时段里勾选「周二 + 周四」，时间 18:00-20:00 → 开始日期选「本周周一」→ 填时薪 150 → 点保存。
- **操作路径**：课程安排 → 添加课程 → 表单 → 保存
- **解说词**：一次录完学生的年级、科目和时间段，课表跟着自动铺开。

### 镜头 3｜16-24s：额度提示（体现试用规则）
- **画面**：再快速添加第 2 门（英语）、第 3 门（物理）→ 列表顶部显示「**试用最多添加 3 门课程，还可添加 X 门**」以及顶部提示条「试用模式：您的排课数据暂时保存在本机浏览器……」→ 鼠标划过该提示条停留 1 秒。
- **操作路径**：课程安排 → 再添加两门 → 提示条 / 额度文案
- **解说词**：免注册试用最多能排 3 门课，数据先存在本机浏览器里。

### 镜头 4｜24-36s：课表自动排好了
- **画面**：点顶部导航「**课表**」→ 展示整周课表（三种颜色的卡片：历史课时 / 进行中 / 未开始）→ 点右上「**导出图片**」→ 生成并保存 PNG（可切到下载目录预览一下带水印的图，停留 2 秒）。
- **操作路径**：顶部导航 → 课表 → 导出图片
- **解说词**：一周排得清清楚楚，还能一键导出带水印的课表图，直接发家长。

### 镜头 5｜36-44s：换日期看其他周
- **画面**：点「**下周**」→ 课表跟着平移 → 再点左侧日期区间改成一个自定义区间（比如跨两周）→ 点「**本周**」回到当前周。
- **操作路径**：课表 → 下周 → 自定义日期区间 → 本周
- **解说词**：想看哪周切哪周，也可以自定义任意日期区间。

### 镜头 6｜44-52s：注册，数据不再丢
- **画面**：点顶部「**登录**」→ 登录弹窗切到「注册」→ 填用户名 / 密码 / 邀请码 → 注册成功 → 自动弹出「检测到本机有 3 门试用课程尚未保存到账号，是否立即导入？」→ 点「**立即导入**」→ 成功提示「已导入 3 门课程到您的账号」→ 顶部提示条消失。
- **操作路径**：头部登录 → 注册 → 导入提示 → 立即导入
- **解说词**：想长期保存就注册一下，刚才排好的课自动导入账号，换台设备也能看。

### 镜头 7｜52-55s：稳住
- **画面**：回到课表页面停留 2 秒（画面干净、无弹窗）。
- **解说词**：课满满 —— 排课省心，课表自动生成。
