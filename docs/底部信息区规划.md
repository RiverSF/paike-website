# 底部信息区规划（推广位 / ICP 备案 / 政策链接）

> **状态：仅规划，暂不执行。** 本轮不改动任何代码，待备案信息落地或推广合作明确后按阶段实施。
>
> 对应代码位置：`web/src/layouts/MainLayout.vue`（`layout-footer`）、`web/src/config/brand.js`（品牌与备案信息统一出口）。

## 一、现状

当前底部只有两行居中文案（`MainLayout.vue`）：

```
课满满 · 课表订单管理工具
注册即送 30 天会员，课程与课表功能对会员开放
```

- 品牌名、站点定位、备案网站名等已集中在 `config/brand.js`，改文案只动这一处；
- 底部为全站共用（所有页面走 `MainLayout`），登录前后、不同身份看到的是同一份；
- 没有备案号、政策链接、推广位，也没有任何可配置开关。

## 二、目标

把底部从「两行固定文案」升级为**三段式信息区**，每段可独立开关、独立配置，按需逐段点亮：

| 段落 | 内容 | 数据来源 | 上线前提 |
| --- | --- | --- | --- |
| ① 站点信息 | 品牌名 · 站点定位（现有） | `config/brand.js` | 已有 |
| ② 合规信息 | ICP 备案号、公安备案、版权年份、政策链接 | `config/brand.js`（静态） | 备案号下发后 |
| ③ 推广位 | 自营活动 / 合作推广 / 工具推荐 | 后端 `site_config`（动态） | 有明确推广需求时 |

原则：**任何一段为空则整段不渲染**，不占位、不显示空白行，避免出现"看起来像加载失败"的空档。

## 三、待展示内容清单

### 3.1 合规信息（优先级最高，属于上线前置条件）

- ICP 备案号：`<a href="https://beian.miit.gov.cn" target="_blank" rel="noopener noreferrer">京ICP备xxxxxxxx号</a>`；
- 公安备案（网站标识码 + 公安网安图标图片），拿到后再补；
- 版权行：`© 2026 课满满`（年份由代码取当前年，避免每年手改）；
- 政策 / 条款链接：用户协议、隐私政策、会员服务说明（当前产品还未提供，先留位，不放空链接）。

### 3.2 推广位（按收益排序，优先级待定）

1. **自营活动位**：会员充值优惠、邀请活动、新功能上线，图片 + 一句话 + 跳转站内页；
2. **合作推广位**：第三方教培工具、教辅资料、打印服务，按 `slot` 位配置，支持多广告位轮换；
3. **工具推荐位**：二维码 / 引导关注，在移动端单独占一行。

推广位默认**关闭**，由后端配置决定是否展示，前端不写死任何具体合作内容。

## 四、配置设计（草案）

### 4.1 静态部分：扩展 `config/brand.js`

```js
export const brand = {
  // ...现有字段
  icp: '',            // ICP 备案号，如 '京ICP备12345678号'，未取得时留空
  policeBeian: '',    // 公安备案编号
  policeBeianImg: '', // 公安备案图标
  links: {            // 政策链接，key-value 形式，未上线的不要放空 key
    terms: '/terms',
    privacy: '/privacy'
  }
}
```

### 4.2 动态部分：新增 `site_config` 单行配置表（与 `price_config` 同构）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | int | 固定为 1 |
| `promo_enabled` | bool | 推广位总开关 |
| `promo_slot` | string | `home` / `orders` / `all`，控制展示范围 |
| `promo_title` | string | 主文案 |
| `promo_desc` | string | 副文案 |
| `promo_image_url` | string | 图片（可选） |
| `promo_link` | string | 跳转地址（站内相对路径或 https 外链） |
| `promo_start` / `promo_end` | bigint | 生效时间窗口（Unix 秒），0 表示不限 |
| `promo_weight` | int | 多素材轮换权重，预留 |

读取沿用现有 `/price` 的公开只读接口风格（`GET /site/promo`，无需登录），管理端写入复用后台价格设置页的保存模式（`PUT /admin/site/promo`）。

## 五、渲染规则

1. 三段自上而下堆叠，整体居中，行距 `4px`，字号 `13px`，颜色沿用 `--brand-sub`；
2. ① 恒显示；② 中任一项为空则该项不渲染；③ 仅当 `promo_enabled = true` 且命中时间窗口与 `promo_slot` 时显示；
3. 外链统一 `target="_blank" rel="noopener noreferrer"`，并加 `aria-label`；
4. 移动端（< 768px）：推广位图片不超宽（`max-width: 100%`），公安备案图标高度 `14px`；
5. 推广位不得遮挡主流程（课表、订单），且不做弹窗、不做浮层、不做倒计时骚扰；
6. 骨架预留：给推广位容器固定 `min-height`，避免上线后因内容加载导致页脚抖动（CLS）。

## 六、合规注意事项

- **ICP 备案是上线前置条件**：域名解析到境内服务器并对外提供服务后需完成备案，备案号取得前第 ② 段保持空白即可，不要伪造占位号；
- 宣传用语需避开绝对化表述（"最""第一""国家级"等）与教育培训类禁用承诺（不得出现"保过""提分承诺""招生"等），与 `docs/站点命名建议.md` 的合规口径保持一致；
- 推广内容需与主站业务相关，禁止接入灰产、博彩、擦边类广告；
- 用户手机号等个人信息不得出现在推广素材中；推广跳转如带参数，需符合隐私政策披露范围；
- 第三方推广需保留可追溯的投放记录（配置变更留痕），便于事后核查。
