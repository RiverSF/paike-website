# 站点命名建议

> 定位：面向**家教老师 / 教培机构 / 中介平台**的「订单 + 周课表 + 课时收入」管理工具。
> 目标：好记、好念、好搜、可注册商标与域名，能一句话说清是干什么的。

---

## 一、同类站点命名规律参考

| 类型 | 代表站点 | 可借鉴的规律 |
| --- | --- | --- |
| 叠词 / 口语 | 轻轻家教、掌门 1 对 1、跟谁学、作业帮 | 2–3 字、口语化，口头转介绍零成本 |
| 具象物象 | 海风教育、橙啦、小叶子 | 一个画得出来的东西，logo 与周边成本低 |
| 品类直白 | 校宝在线、校管家、爱耕云、ClassIn | 客户一眼看懂，但重名率高、不易注册 |
| 工具类 | 超级课程表、番茄表单 | 以功能词为核心，搜索心智强 |

**结论**：教育类产品的高传播名字普遍是「2–3 字 + 口语/叠词 + 具象意象」。我们应在名字里带一个品类词（课 / 课时 / 家教 / 老师），兼顾搜索心智与口碑传播。

---

## 二、主推 3 个

### ① 课满满 ⭐ 首推

- **记忆点**：谐音「满满」，一语双关 —— 课时排得满、收入收得满，正好命中我们「周课表 + 课时收入统计」的核心卖点。
- **结构**：叠词结构，与「轻轻家教」同款记忆模型，口播一次就能写对。
- **视觉**：logo 可用「被课程填满的日历 / 课表格子」，成本低、辨识度高。
- **Slogan**：排课满满，课时清清楚楚
- **域名**：`kemanman.com` / `kemm.cn`（需查注册情况）

### ② 叮课（DingClass）

- **记忆点**：拟声词，天然带「上课提醒、调课通知」的联想。若后续做上课提醒 / 调课通知，名字自带功能说明。
- **结构**：单音节 + 单字，极易口播转介绍；英文 DingClass 便于未来做独立品牌。
- **视觉**：铃铛 + 课表格图形。
- **Slogan**：临时调课，叮一下就搞定
- **域名**：`dingke.cn` / `dingclass.com`

### ③ 课时宝 / 课酬通

- **记忆点**：直给型，突出「课时统计 + 收入结算」，对机构与中介的主决策人转化率最高。
- **不足**：B 端感重、品牌延展性弱于前两个。
- **Slogan**：课时、课酬一本账

## 三、备选池

| 方向 | 候选 | 说明 |
| --- | --- | --- |
| 具象 IP | 排课猫、课表喵、课虫 | 好做表情包与周边，适合 C 端老师自发传播 |
| 动作型 | 搭课、约课、补课簿 | 「补课簿」亲切（老师记课时的小本子），但「簿」(bù) 难打，推广吃亏 |
| 英文混搭 | TutorBoard、Classly、Teachly | 适合未来出海 / 独立品牌，国内口播差 |

## 四、命名红线

1. **字数**：2–3 字，避生僻字（口头转介绍要能一次写对）。
2. **品类词**：首字含「课 / 家教 / 老师」，利于搜索心智。
3. **可注册**：先查 `.com` / `.cn` 域名，再查第 41 类（教育）与第 42 类（软件）商标。
4. **避让**：避开与「轻轻家教、掌门、校宝、超级课程表」等近似度高的组合。

## 六、路线 B（正规经营）：公司注册名与备案网站名建议

> 背景：路线 B 需 **注册经营主体 → 企业备案 →（含在线付费）办 ICP 许可证 → 教育类视当地管局要求补前置审批**。
> 命名策略核心：**公司行业用「信息科技 / 网络科技 / 软件科技」而非「教育科技」，降低触发教育前置审批的概率**；**备案网站名用中性、与字号强关联的词，避开「家教 / 培训 / 招生 / 交易 / 商城」等易触发人工审核的敏感词**。
> 品牌字号从 **第七节** 选定后，套入下方示例即可。

### 6.1 公司全称框架（营业执照用）

以候选字号套用，行业按"信息 / 网络 / 软件科技"三选一：

| 字号（示例） | 推荐公司全称 | 行业选择理由 |
| --- | --- | --- |
| 课树 ⭐ | 课树（所在城市）信息科技有限公司 | 「信息科技」规避教育前置审批，业务挂靠"信息系统集成/软件服务"更稳 |
| 排课啦 | 排课啦（所在城市）网络科技有限公司 | 「网络科技」中性，直指排课功能 |
| 课伴 | 课伴（所在城市）软件科技有限公司 | 「软件科技」强调工具属性 |

> 组织形式可选：**有限责任公司**（推荐，责任有限、便于融资/开票）或 **个体工商户**（成本最低，但无法办 ICP 许可证、不能开分店，不适合路线 B 的付费经营，仅适合轻量试水）。
> 「所在城市」按实际注册地填（如上海市 / 深圳市 / 杭州市），工商名称与后续备案主体必须一致。

### 6.2 备案网站名称（企业主体，管局审核用）

套用规则：**网站名 = 品牌字号 + 中性后缀**，务必包含字号。

| 网站名称 | 适用场景 | 备注 |
| --- | --- | --- |
| {字号}官网 | 主站 | 与字号强关联，最稳，多数管局直接过 |
| {字号} · 学习成长管理工具 | 官网 / 平台 | 中性描述，主动规避"家教 / 培训"敏感词 |
| {字号}管理后台 | 产品站 | 弱化 C 端招生感，偏工具定位 |

### 6.3 命名红线补充（备案侧）

1. **别碰前缀词**：网站名称不得含「中国 / 中华 / 全国 / 国家 / 国际」等，这些需部级审批，个人与企业都几乎批不下来。
2. **敏感词触发前置审批**：网站名或对外文案含「家教 / 培训 / 教育 / 招生 / 教学」等词，多数管局会要求提供 **教育主管部门前置审批文件**；建议全站统一用「课表 / 订单 / 课时 / 学习成长管理工具 / 信息平台」等中性词（含"课 / 排课"均安全）。
3. **字号一致性**：企业备案网站名称若与营业执照字号不一致，部分管局直接驳回；**网站名务必包含公司字号**。
4. **主体一致**：域名注册人/实名认证主体 = 备案主体 = 营业执照主体，三者不一致接入商核验不过。
5. **ICP 许可证是另一道关**：即便公司名、网站名都合规，只要网站有"在线付费 / 会员续费"，企业备案后还需办 **ICP 经营许可证（增值电信业务，仅互联网信息服务）**，与备案是两码事，域名主体同样要一致。

### 6.4 落地

品牌名选定后，在 `web/src/config/brand.js`（已抽成统一出口）配置：

```js
export const brand = {
  brandName: '{{ 最终选定的品牌字号，如 课树 }}',
  siteDesc: '学习成长管理工具',
  companyName: '{{ 品牌字号 }}（所在城市）信息科技有限公司',
  siteTitle: '{{ 品牌字号 }} · 学习成长管理工具',
  metaDesc: '学习成长管理工具，支持课表排期、学习记录与成长跟踪。'
}
```

`index.html`、`router/index.js`、`AppHeader.vue`、`MainLayout.vue`、`HomeView.vue`、`package.json` 全部引用 `brand.*`，改名只动一处。

## 七、最终命名总览（合并「课」与「排课」两轮推荐）

> 范围：服务对象仍是**老师 + 家长 C 端**，功能从排课扩展为**学习 / 成长管理**。
> 约束：**顺口好记**为首要，**点出功能**次之；含"课"保搜索心智、含"排课"最直给，二者均中性、不踩备案敏感词。
> 结论：合并两轮推荐，收敛为「最推荐」与「优先备选」两类；域名与 Logo 方案一并整理。

### 7.1 最推荐（建议从中定 1 个品牌名）

**① 课树 ⭐**
- 关键字：课｜类型：成长具象
- 记忆点："树"=成长，最贴"学习/成长管理"新定位；含"课"保搜索心智，2 字顺口、重名低。
- 域名：`keshu.com` / `keshu.cn` / `keshu.app`
- Logo 方案：一棵树由课表格子构成（蓝/绿渐变 + 柔和投影）；favicon 取树冠。

**② 排课啦**
- 关键字：排课｜类型：口语语气
- 记忆点："啦"活泼，像"排课啦！"的口头号召，最顺口、C 端转介绍零成本，功能最直给。
- 域名：`paike.la` / `paike.cn` / `paike.app`
- Logo 方案：课表卡片 + 感叹号 / 小火花。

**③ 课伴**
- 关键字：课｜类型：温情关系
- 记忆点："伴"=陪伴，学习好搭档，老师/家长/学生都买账，C 端友好。
- 域名：`keban.com` / `keban.cn`
- Logo 方案：圆角"课"字徽章 + 陪伴小圆点。

### 7.4 命名红线（汇总）

1. **字数**：2–3 字，避生僻，口播一次能写对。
2. **不踩备案敏感词**：网站名/文案避开「家教 / 培训 / 招生 / 教育 / 教学」；用「课表 / 订单 / 课时 / 学习成长管理工具 / 信息平台」等中性词（含"课 / 排课"均安全）。
3. **可注册**：先查 `.com / .cn` 域名，再查第 41 类（教育）与第 42 类（软件）商标；叠词 / 短拼（课满满 / 排课啦 / 课啦）重名概率高，务必实测。
4. **避让**：避开「作业帮 / 小叶子 / 超级课程表 / 校宝 / 掌门」等近似组合。
5. **字号 + 主体 + 许可**：沿用 6.3 第 3–5 条（字号一致、主体一致、ICP 许可证）。
